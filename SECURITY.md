# mlaify.io security reporting

This repository and website follow the
[mlaify organization-wide security reporting policy](https://github.com/mlaify/.github/blob/main/SECURITY.md).
That is the single canonical policy for `mlaify` projects.

The policy explains that these projects are worked on by just one person, and coordinated
vulnerability disclosure (CVD) and the vulnerability disclosure policy (VDP) are best effort; there
is no bug bounty or paid disclosure program; no payment, rewards, or swag are offered; and a
report does not create an obligation to respond, investigate, fix, publish, credit, or coordinate.

For a credible, confidential vulnerability in this website, use this repository's **Security**
tab and select **Report a vulnerability**. Use a public issue for ordinary site bugs, broken
links, content corrections, and feature requests. Reports sent by email are not processed.

This repository and the deployed `mlaify.io` site are the project-specific systems in scope.
